## Рабочая папка, индекс и коммит
* **Рабочая папка (Working Directory)** - текущие файлы проекта, расположенные накомпьютере.
* **Индекс (Index)** - подготовленное состояние файлов для вклбчения в следующий коммит.
* **Коммит (Commit)** - фиксация изменений с комментарием.

## Разница между Git и GitHub
* **GitHub** - облачная платформа для хранения репозиториев.
* **Git** - система контроля версий.

## Использованные команды
* **git diff** - сравнивает рабочую папку и индекс.
* **git diff --staged** - сравнивает индекс и последний коммит.
* **git status** - показывает изменения неготовые к коммиту, изменения, готовые к коммиту и неотслеживаемые файлы.

## Ветки
* **Ветка** - независимая линия разработки, указывающая на определённый коммит.
* **При новом коммите** - указатель текущей ветки автоматически сдвигается вперёд на этот коммит.
* **Слияние** - перенос из одной ветки в другую.
